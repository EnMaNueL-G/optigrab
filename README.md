# OptiGrab

Reproductor y **descargador privado** de vídeo y audio: YouTube, X/Twitter, Facebook, Reddit, Vimeo, TikTok e Instagram y **+1000 sitios**. Para **Windows y Android**. Gratis, sin anuncios ni rastreadores: todo se procesa en tu equipo.

## Descargas
- **Windows 10/11** (portable, sin instalar): [OptiGrab-Portable.zip](https://github.com/EnMaNueL-G/optigrab/releases/latest/download/OptiGrab-Portable.zip). Descomprime y abre `OptiGrab.exe`.
- **Android 7+** (APK): [OptiGrab.apk](https://github.com/EnMaNueL-G/optigrab/releases/latest/download/OptiGrab.apk).
- Más información: **https://optisuite.app**

## Qué funciona en cada una
| | Windows | Android |
|---|---|---|
| YouTube (hasta 4K), X, Facebook, Reddit, Vimeo… | ✅ | ✅ |
| TikTok | ✅ | ❌ (TikTok bloquea la descarga desde el móvil) |
| Instagram | ✅ con la sesión de tu navegador | ❌ (pide iniciar sesión) |
| Canales / perfiles / listas enteras | ✅ | ✅ (YouTube) |
| Motor que se actualiza solo | ✅ | ✅ |

## Novedades v1.1.0
- YouTube vuelve a ofrecer hasta **4K** (antes se quedaba en 360p). TikTok funciona en Windows.
- El **motor de descarga se actualiza solo** una vez al día, y la app avisa si hay versión nueva.
- **Pausar y cancelar paran de verdad**, y al reanudar continúa donde iba.
- Windows: carátula en los MP3, opción **H.264** para TV/WhatsApp, subtítulos, límite de velocidad, sesión del navegador para sitios con login, títulos con emojis.
- Android: analiza el enlace antes de bajarlo, lista canales enteros, varios enlaces a la vez, **MP3 de YouTube**, compartir desde otras apps, idioma de audio (por defecto la pista original), APK más ligero (123 MB).

El **código fuente es privado**. Incluye yt-dlp (Unlicense) y FFmpeg (GPL). Parte del ecosistema **OptiSuite**: https://github.com/EnMaNueL-G
